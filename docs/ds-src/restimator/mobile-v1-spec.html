Spec de implementación — Mobile

Versión final y bloqueada de las tres pantallas mobile core: Calculadora · Inicio · Historial. Una sola variante por pantalla, con medidas, spacing, componentes y comportamiento sticky listos para construir en Claude Code. No hay ideas nuevas ni patrones nuevos: se mantiene navegación inferior, header compacto, recomendado visible arriba y bottom sheet sólo para el desglose.
